# SolidWorks MCP 开发

维护现有 SolidWorksMCP-python 实现，优先修复或扩展已有能力。

## 运行约束
- 修改前检查当前 Git 状态、实际启动入口和相关调用代码。
  未跟踪文件先识别用途，不自动删除或纳入提交。
- 保留真实 SW2020 模式；启动配置变化时核对各实际使用入口。
- 服务初始化和 tools/list 不建立 COM 连接；
  需要 SolidWorks 的业务调用才按需连接，COM 操作串行执行。
- stdio 的 stdout 仅用于 MCP 协议，诊断日志写入 stderr。
- 参数检查尽量在修改文档前完成。
  工具结果应能区分成功、失败、部分完成和结果未知。
- 不把超时等同于未执行；重试前核实文档状态和请求记录。
- 注册检查不得通过会启动 SolidWorks 的 COM 创建调用完成。

## 按需资料
- 启动、连接、协议或重试问题：读取 [运行契约](references/runtime-contract.md)。
- 涉及现有接口实现：查阅仓库对应代码及相关官方版本文档，
  不预先读取全部文档。

## 验证
验证被修改工具的实际行为及受影响的运行约束。
涉及建模副作用时，在测试副本中验证，并记录文件与关键结果。
无需为普通代码修改执行完整建模回归。
