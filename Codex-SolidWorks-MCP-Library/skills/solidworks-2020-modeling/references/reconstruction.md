# 参考图重建

先识别连接关系、孔槽、对称、厚度和可见/遮挡边；区分图上明确尺寸、用户约束与推定尺寸。透视图和像素比例不能当作精确工程尺寸。

若图形存在空间歧义，先判断是否影响实体拓扑或装配关系。只询问会改变结果的缺失信息；可以先完成结构分析。用户允许参数自定时，选取合理参数并披露假设，但仍遵守明确几何约束。

把模型转成最小必要的参数和特征关系。例如各伸出棱等厚，使用全局变量“厚度”及方程/等厚关系驱动相关特征，在模型内部保留关联。修改共享参数后确认相关尺寸共同更新；不止核查当前数字一致。

按设计意图选择草图、拉伸、切除、阵列等。优先稳定基准和明确引用，避免依赖易变的面/边序号。无需为简单零件增加无关装配、配置或工艺设计。

交付视图应能看清主要结构，必要时补第二视角；将尚未由图纸确定的参数标为自定或假设。几何验证方法见 [验证与恢复](verification-recovery.md)。
