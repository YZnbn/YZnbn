### 2.4 SSRF 防护 — 通过（主动防护，加分项）

`ui/local_llm.py` 实现了显式的 URL scheme 白名单：

```python
_ALLOWED_SCHEMES = frozenset({"http", "https"})

def _require_http_endpoint(url: str) -> None:
    """Guards every urllib.request.urlopen call so that attacker-controlled
    endpoint values cannot redirect requests to file:// or other
    non-network schemes (CWE-22 / Bandit B310)."""
    scheme = urllib.parse.urlparse(url).scheme.lower()
    if scheme not in _ALLOWED_SCHEMES:
        raise ValueError(...)
```

**并且配有回归测试**（`tests/solidworks_mcp/ui/test_local_llm.py:252`）：

```python
def test_require_http_endpoint_rejects_file_scheme() -> None:
    """file:// is rejected to prevent local-file exfiltration."""
    with pytest.raises(ValueError, match="http or https"):
        _require_http_endpoint("file:///etc/passwd")
```

即：不仅防了 SSRF 与本地文件外渗，还写了测试锁死行为。**这是发布前审查中的正向证据。**

## 三、观察项（非漏洞，但建议发布前处理）

### 3.1 ~~`CLAUDE.md` 的 BOM 描述会触发自动扫描器~~ — ✅ 已修复

**原现象**：文件内包含 `\ufeff` 字面量（作为文档说明），自动化工具会将其标记为「潜在提示注入」并拒绝加载该文件。

**影响**：任何使用同类防护机制的 AI 工具链（含本次扫描所用工具）都会跳过 `CLAUDE.md`，导致其工程规范无法被 AI 读取。

**处理**：已将第 194 行改写为不含字面义 BOM 序列的转义写法。

**复检证据**：
```
文件大小      14,439 → 14,442 字节（转义写法多 3 字符）
U+FEFF 计数   1 → 0
裸 BOM 字节   0
重新加载状态  正常，不再被拦截
```

### 3.3 CI 中 Trivy Action 使用了版本标签而非 commit SHA — ⚠️ 仍存在

### 3.4 SolidWorks 2026 API 兼容性 — ⚠️ 新增（本次复检发现）

**现象**：`FeatureCut3` 在 SolidWorks 2026 上拒绝 2020 版适配器构造的参数表：

```
Failed to create cut extrude feature.
FeatureCut3 legacy: (-2147352561, '非选择性的参数。', None, None)
```

`-2147352561` = `DISP_E_PARAMNOTOPTIONAL`（参数不可省略）。

**性质**：功能兼容性问题，**非安全漏洞**。原因 SW2020 与 SW2026 类型库之间的
API 签名漂移。通过 `sw2020_build_batch` 封装层与通用 `create_cut_extrude`
工具均可复现，两者最终走到同一底层 COM 调用。

**影响面**：仅切除类特征。增料（Boss/Extrude）不受影响。

**安全影响**：无。不引入注入面、不提权、不扩展网络暴露。

**建议**：修 `pywin32_adapter.py` 中的 `FeatureCut3` 调用点做版本自适应，
或用 VBA 宏（`FeatureCut3` → `FeatureCut4` / 孔向导 API）绕过。

## 五、未覆盖项（诚实说明）

**依赖供应链 CVE 扫描未完成。**

原因：本次扫描环境的网络无法访问漏洞数据库：

- `api.osv.dev`（OSV 官方 API）— WSL 与 Windows 两侧均返回 `Connection reset by peer`，为网络层阻断
- 常见本地代理端口（7890/7897/10809）— 均 `Connection refused`

**已测得的事实**：`uv.lock` 共解析 **285 个包**，关键组件版本均较新（2026 年发布）：

```
fastmcp==3.4.2       mcp==1.28.1          pydantic==2.12.5
pydantic-ai==1.107.0 starlette==1.3.1     fastapi==0.137.2
urllib3==2.7.0       jinja2==3.1.6        cryptography==50.0.0
aiohttp==3.14.3      pyjwt==2.13.0        python-multipart==0.0.32
```

**建议**：仓库已配置 `pip-audit` CI 工作流（`.github/workflows/security-scan.yml`），在 GitHub Actions 上网络可达，推送后即可获得权威 CVE 结果。**无需本地重复扫描。**

**本报告不声称 CVE 覆盖。** 未查询的漏洞库不能以「未发现问题」表述——这是未覆盖项，不是通过项。
