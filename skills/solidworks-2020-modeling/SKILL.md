# SolidWorks 2020 建模

交付可编辑的原生模型，使草图、拉伸、切除、阵列等实际出现在特征树中。

## 建模约束
- 使用真实 SW2020 API/COM 或对应 MCP；模拟结果不能作为建模完成证据。
- 修改前确认目标文档、保存状态和输出位置，默认在副本或新版本中工作。
- 明确单位、关键尺寸和几何关系。只有用户授权“参数自定”时，
  才自行补充影响几何的缺失尺寸，并说明假设。
- 相同设计参数使用共同变量、方程或几何关系关联；
  “厚度相同”等要求不能只靠分别输入相同数值实现。
- 自定义特征名称采用中文功能名称；代码标识符和 API 字段保留原名。
- 根据几何关系选择特征顺序，不固定为同一套操作模板。

## 按需资料
- 首次连接或环境异常：读取 [环境](references/environment.md)。
- 从图片或图纸重建：读取 [参考图重建](references/reconstruction.md)。
- 模型交付或调用结果不明确：读取 [验证与恢复](references/verification-recovery.md)。
- 新建草图及拉伸/切除组合，或比较建模结果：读取 [结构化计划与结果比对](references/structured-plan.md)。

## 交付
提供模型路径、关键参数、实际验证结果和剩余限制。
涉及形状判断时提供最终视图；图片不能代替特征和几何验证。
