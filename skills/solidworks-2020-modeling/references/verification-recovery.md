# 验证与恢复

## 按改动选择证据
- 几何变更：重建并检查相关错误、特征定义、抑制状态、实体数量和关键尺寸。实体数量按设计判断，不固定为一个。
- 共享参数：读取关联方程/关系；需要时在工作副本中改变参数并重建验证传播，再恢复交付值。
- 有可推导体积时核对解析预期和容差；没有可靠预期时不编造体积验收值。质量判断需要真实材料/密度；材料文字备注不等于物理材料赋值。
- 保存交付：核对目标新路径、保存错误/警告、文件存在和文档状态。文件存在本身不证明正确；必要时重新打开输出验证，不关闭或覆盖用户未保存文档。
- 形状任务：补最终视图作为外观证据。重命名等小改动只检查受影响内容和保存结果。

不要只匹配特征字符串 `Boss`：已有 SW2020 记录中拉伸返回 `Extrusion`，需结合实际定义和实体判断。
包围盒可为近似值，关键尺寸优先查真实尺寸、几何或方程；只取顶点不能覆盖曲面极值。

## 调用异常
`success` 表示该调用成功，不等于模型满足全部要求；`partial` 表示可能已有变更；超时或进程退出后记录停在 `started` 时结果未知。

出现部分完成或未知结果，保留文档身份、请求 ID、参数、最后特征与日志，先检查现场。批量工具通常不具有事务回滚，不能假设失败后模型未变。
同一请求 ID 的历史响应不能作为实时验证；不要为了绕过重放保护换 ID 重试。确认未执行或已安全恢复后，才根据工具契约继续。

可在授权工作副本中修复本次新增失败特征，保留用户原有内容。恢复不了时保存诊断信息并说明阻塞；不强杀用户 SolidWorks 或另起修改会话绕过占用。
