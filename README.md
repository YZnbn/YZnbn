# 杨洲

贵州大学机械设计制造及其自动化专业本科生，参加贵州大学与美国北阿拉巴马大学合作的中美双学士项目。关注机器人机械结构、传动系统与整机集成，乐于把设计方案推进到可制造、可装配、可验证的样机。

## 经历

- **机器人研发与结构设计**：参与创立机器人企业并负责结构研发，围绕地震救援场景设计机器人结构与传动方案，协调零部件加工、样机装配及机械、电控和传感模块联调，并与救援队开展场景验证。
- **VEX 机器人指导**：担任机械导师，指导机器人结构、齿轮传动和执行机构设计，协助团队进行装配、调试和竞赛迭代。
- **汽车制造实践**：在吉利汽车总装与焊装相关部门实习，了解设备运行维护、生产节拍与制造流程。

## 项目与研究

- **地震救援机器人**：担任项目负责人及机械结构设计，负责底盘、履带、传动、外壳和功能模块的方案设计与迭代，参与样机装配及测试验证。
- **深海珊瑚修复机器人**：负责机械结构与装配设计，关注深水压力、密封、低温和海水腐蚀环境下的结构可靠性，并参与低损伤柔性夹爪设计。
- **VEX U 竞赛机器人**：负责机械结构、齿轮传动与 SolidWorks 建模装配，根据训练和比赛问题持续调整结构方案。
- **AlCrTiZr 高熵合金涂层研究**：参与涂层研究，关注表面处理工艺及材料硬度、结合性能、耐腐蚀和耐磨性能。

## 技术方向

- 使用 SolidWorks 进行零件建模、整机装配、工程图和运动仿真，具备结构迭代与拓扑优化经验。
- 熟悉常见电机、减速器和齿轮传动方案的选型与匹配，关注强度、重量、加工、装配和维护之间的平衡。
- 了解金属、工程塑料、碳纤维及柔性材料的选型，接触冲压、焊接、机加工、3D 打印和表面处理工艺。
- 有机械与电控协同经验，参与传感器、执行机构接口集成及 PID 运动调试。
